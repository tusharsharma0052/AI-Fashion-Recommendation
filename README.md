# 👗 AI Fashion Outfit Recommendation System

An end-to-end AI-powered fashion assistant that understands natural language,
retrieves products using vector search, scores outfit compatibility, and explains
every recommendation in conversational prose.

---

## ✨ Features

| Feature | Implementation |
|---|---|
| Natural language intent extraction | Gemini 1.5 Flash |
| Semantic product retrieval | FAISS + Sentence Transformers |
| Multi-modal embeddings | CLIP (optional) + all-MiniLM-L6-v2 |
| Outfit compatibility scoring | Weighted multi-signal engine |
| Colour harmony analysis | Curated colour harmony matrix |
| Conversational memory | Session-scoped history |
| Explainable recommendations | Gemini explanation generator |
| Chat UI with product cards | Streamlit |

---

## 🏗️ Architecture

```
User Query
    │
    ▼
┌─────────────────────┐
│  Gemini Intent      │  Extracts: gender, occasion, style,
│  Extraction         │  season, colour, age, specific items
└────────┬────────────┘
         │ UserProfile JSON
         ▼
┌─────────────────────┐
│  Embedding          │  all-MiniLM-L6-v2 → 384-d text vector
│  Generation         │  (+ CLIP 512-d image vector, optional)
└────────┬────────────┘
         │ query embedding
         ▼
┌─────────────────────┐
│  FAISS Retrieval    │  IVFFlat index, inner-product similarity
│  (per category)     │  Topwear / Bottomwear / Footwear / Acc.
└────────┬────────────┘
         │ candidate DataFrames
         ▼
┌─────────────────────┐
│  Compatibility      │  score = 0.40×embed + 0.20×occasion
│  Engine             │         + 0.15×style + 0.15×colour
│                     │         + 0.10×season × gender_penalty
└────────┬────────────┘
         │ ranked items
         ▼
┌─────────────────────┐
│  Outfit Builder     │  Assembles TOP_K_OUTFITS complete looks
│                     │  with colour-harmonised pieces
└────────┬────────────┘
         │ complete outfits
         ▼
┌─────────────────────┐
│  Gemini Explanation │  2-4 sentence natural-language rationale
│  Generator          │  per outfit
└────────┬────────────┘
         │
         ▼
    Streamlit UI
  (chat + product cards)
```

## 🚀 Setup Instructions

### 1. Clone and enter the project

```bash
git clone https://github.com/DarexAI-AI-Startup/ML-TASK
cd fashion-assistant
```

### 2. Create a virtual environment

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure your API key

```bash
cp .env.example .env
# Edit .env and set GEMINI_API_KEY=your_key_here
```

Get a free Gemini API key at: https://aistudio.google.com/app/apikey

### 5. Place the dataset

Download the dataset from https://github.com/DarexAI-AI-Startup/ML-TASK and:

```
fashion-assistant/
├── data/
│   ├── products.csv
│   └── outfits.csv
└── images/
    └── <product image files>
```

### 6. Run the data pipeline

```bash
# Text embeddings only (fast, recommended for first run)
python setup_pipeline.py

# With CLIP image embeddings (requires ~2 GB VRAM or more RAM, slower)
python setup_pipeline.py --clip

# Force rebuild of all artefacts
python setup_pipeline.py --force
```

### 7. Launch the app

```bash
streamlit run app.py
```

Visit **http://localhost:8501** in your browser.

## 🧰 Module Reference

### `dataset_analysis.py`
- `load_products()` — loads and enriches products.csv
- `load_outfits()` — loads outfits.csv
- `generate_statistics()` — returns category/gender/occasion stats
- `validate_catalog()` — data quality checks
- `build_fashion_catalog()` — convenience wrapper

### `embedding_generator.py`
- `generate_text_embedding(text)` — single query embedding
- `generate_image_embedding(path)` — single CLIP image embedding
- `generate_multimodal_embedding(text, path)` — fused embedding
- `build_and_save_embeddings(products)` — full catalog pipeline
- `load_embeddings()` — load cached .npy files

### `retrieval/faiss_index.py`
- `build_index(embeddings, ids, df)` — build + save FAISS index
- `load_index()` — load from disk
- `search_similar_items(query_emb, ...)` — nearest-neighbour search
- `FashionRetriever` — stateful wrapper class

### `models/compatibility_engine.py`
- `score_item(item, profile, anchor_color)` — single item score
- `recommend_topwear/bottomwear/footwear/accessories(...)` — per-category ranking
- `build_complete_outfit(...)` — full outfit assembly

### `llm/intent_parser.py`
- `extract_user_intent(query)` → UserProfile dict
- `build_retrieval_query(profile)` → rich text query string

### `llm/explainer.py`
- `generate_outfit_explanation(profile, topwear, ...)` → 2-4 sentence explanation
- `generate_style_tips(profile)` → 3 style tips

### `assistant/chat_engine.py`
- `ChatEngine.chat(query)` → `OutfitRecommendation`
- `get_engine()` → singleton instance

## 🔮 Future Improvements

2. **FashionCLIP** — replace generic CLIP with fashion-domain fine-tuned model for richer image embeddings
3. **Try-on preview** — virtual try-on using diffusion models

7. **Body type awareness** — fit and silhouette recommendations based on body type
8. **Multi-language** — support Hindi and other Indian languages via Gemini
9. **Outfit persistence** — save and share outfit recommendations
10. **A/B testing** — compatibility weight optimisation via user feedback
